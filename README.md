## `./hello_world.sh`

Hi, I'm **Sidharth Salugu**, but you can call me **Shido** (my name got refactored for readability). I'm a final-year CSE (AI/ML) undergrad. I build software, poke at AI, and I'm working my way into open source.

Game dev is a childhood hobby that never left, and it's still the dream. (the kid version of me would like a word if I ever gave up on it.)

I turn caffeine into gradient descent, and occasionally into code that compiles on the first try. *(rare. I frame it when it happens.)*

**what I'm about**

- **AI/ML**: training a model is fun. figuring out why it failed is more fun.
- **open source**: reading strangers' code and trying to leave it a little better than I found it.
- **software dev**: I like building things people actually use, not just things that pass the tests.
- **game dev**: I want to know how everything works under the hood, and build the indie way.

I'd rather know *why* something works than just watch it run.

**fun facts, mostly bugs**

- my code has two states: "works" and "no idea why it works, don't touch it".
- I talk to my rubber duck. it has better test coverage than I do.
- I have far too many bookmarked tutorials. that's future me's problem.
- current status: `404 free time not found`.
